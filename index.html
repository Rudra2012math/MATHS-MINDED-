Detailed Concepts

Important formulas and concepts for revision.

1. Real Numbers

Real numbers include rational and irrational numbers. The Euclidean algorithm can be used to find the HCF of two positive integers.

Euclid's Division Lemma: a = bq + r

2. Polynomials

A polynomial is an algebraic expression containing variables with non-negative integer powers.

For ax² + bx + c: Sum of zeros = -b/a
Product of zeros = c/a

3. Pair of Linear Equations

Two linear equations can be solved using substitution, elimination or graphical methods.

ax + by + c = 0
px + qy + r = 0

4. Quadratic Equations

A quadratic equation has the standard form ax² + bx + c = 0.

x = (-b ± √(b² - 4ac)) / 2a

Discriminant = b² - 4ac

5. Arithmetic Progressions

An arithmetic progression is a sequence in which the difference between consecutive terms remains constant.

nth term = a + (n - 1)d

Sum = n/2 [2a + (n - 1)d]

Question 1 — Real Numbers

What is the HCF of 36 and 48?
Correct Answer: 12

Prime factorisation:

36 = 2² × 3²
48 = 2⁴ × 3

Common factors: 2² × 3 = 12

Therefore HCF = 12.

Question 2 — Real Numbers

Which of the following is irrational?
Correct Answer: √2

√2 cannot be represented as a ratio of two integers. Therefore it is an irrational number.

Question 3 — Polynomials

If α and β are zeros of x² - 5x + 6, what is α + β?
Correct Answer: 5

For ax² + bx + c,

Sum of zeros = -b/a

Here a = 1 and b = -5.
Therefore:
α + β = -(-5)/1 = 5

Question 4 — Polynomials

The zeros of x² - 9 are:
Correct Answer: 3 and -3

x² - 9 = 0

(x - 3)(x + 3) = 0

Therefore:
x = 3 or x = -3.

Question 5 — Linear Equations

Solve: x + y = 10 and x - y = 2.
Correct Answer: x = 6, y = 4

Add both equations:

x + y + x - y = 10 + 2
2x = 12
x = 6

Substitute x = 6:
6 + y = 10
y = 4

Question 6 — Linear Equations

If 2x + 3y = 12 and x = 3, find y.
Correct Answer: y = 2

Substitute x = 3:

2(3) + 3y = 12
6 + 3y = 12
3y = 6
y = 2

Question 7 — Quadratic Equations

Find the roots of: x² - 5x + 6 = 0
Correct Answer: 2 and 3

Factorise:

x² - 5x + 6
= (x - 2)(x - 3)

Therefore:
x = 2 or x = 3.
